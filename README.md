# 🌌 Solar System 3D View
This project is a simple 3D visualization of the Solar System built using HTML, CSS, and JavaScript. It gives an animated, interactive representation of planets orbiting the Sun, providing a fun and educational look at our solar system in motion.

# 🌍 Features
🌞 Sun at the center with orbiting planets

🪐 Realistic planet sizes and orbital paths (stylized)

🌀 Smooth animations using CSS and JavaScript

🎨 Clean and responsive layout

💫 Educational and visually engaging

# 🛠️ Technologies Used
HTML5

CSS3 (3D transforms, animations)

JavaScript (for orbit logic and interactivity)

# 📁 Project Structure

├── index.html        
├── style.css         
├── script.js         
# 🚀 How to Run
Clone the repository or download the files.

Open index.html in a modern browser.

Enjoy the animated solar system view!
